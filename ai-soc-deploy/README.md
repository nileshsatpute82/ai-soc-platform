## 5-Minute Deployment to Render.com

### Step 1: GitHub (2 minutes)
```bash
git init
git add .
git commit -m "AI SOC Platform Demo"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ai-soc-demo.git
git push -u origin main
```

### Step 2: Render.com (2 minutes)
1. Go to **render.com** → New Web Service
2. Connect GitHub repo: `ai-soc-demo`
3. Auto-deploy from `main` branch
4. Done! 

### Step 3: Test (1 minute)
Visit your live app: `https://ai-soc-demo.onrender.com`
